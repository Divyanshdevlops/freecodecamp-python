# 🎬 Movie Ticket Booking Calculator

A beginner-friendly Python program that calculates the cost of movie tickets based on the booking details provided by the user.

## ✨ Features

* Accepts movie booking information
* Calculates ticket costs
* Uses user input
* Displays the final booking cost

## 🛠️ Built With

* Python 3

## ▶️ How to Run

Open a terminal inside this folder and run:

```bash
python main.py
```
