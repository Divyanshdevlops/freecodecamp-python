# 👨‍💼 Employee Card Generator

A simple Python command-line program that generates an employee card from information entered by the user.

## ✨ Features

* Takes an employee's name as input
* Takes their position as input
* Takes their employee ID as input
* Displays the information in a formatted employee card

## 🛠️ Built With

* Python 3

## ▶️ How to Run

Clone the repository and navigate to the project:

```bash
cd projects/employee-card-generator
```

Run the program:

```bash
python main.py
```

## 💻 Example

```text
Enter employee name: Divyansh
Enter employee position: Python Developer
Enter employee ID: 001

========================================
         EMPLOYEE CARD
========================================
Name:        Divyansh
Position:    Python Developer
Employee ID: 001
========================================
```
