# 💰 Bill Splitter

A simple Python program that calculates how much each person should pay when splitting a bill.

## ✨ Features

* Enter the total bill amount
* Enter the number of people
* Enter the tip percentage
* Calculates the total with tip
* Calculates the amount each person should pay

## 🛠️ Built With

* Python 3

## ▶️ How to Run

Open your terminal inside this folder and run:

```bash
python main.py
```

## 💻 Example

```text
Enter the total bill: 100
Enter the tip percentage: 10
Enter the number of people: 4

Each person should pay: $27.50
```
